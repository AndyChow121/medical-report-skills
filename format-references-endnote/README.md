# Format References (EndNote) · EndNote 文献排版

> 中文 | English

## 简介 / Introduction

**中文** — 将手稿中的 [PMID:xxxx] 转为 Word(.docx)，写入 EndNote CWYW 识别的 {Author,Year,Title} 占位符，并生成 .ris 导入本地 EndNote；在 Word 中点一次「Update Citations」即完成排版。仅适用于 EndNote 用户。

**English** — Convert manuscript [PMID:xxxx] into Word (.docx) with EndNote CWYW {Author,Year,Title} placeholders, plus a .ris file for local EndNote import; one "Update Citations" in Word finishes formatting. EndNote users only.

## 核心能力 / Key Features

- [PMID] → Word + EndNote 占位符 — [PMID] → Word + EndNote placeholders
- 生成 .ris 一键导入 — .ris export for one-click import
- 仅 EndNote 工作流 — EndNote workflow only

## 适用场景 / Use Cases

- EndNote 用户的参考文献终排版
- 手稿转可投稿 Word

## 快速开始 / Quick Start

- 中文：调用 Skill `format-references-endnote`，附含 [PMID] 的手稿。
- English：Invoke Skill `format-references-endnote` with the [PMID]-tagged manuscript.

## 安装 / Install

把本目录复制到 WorkBuddy 的 skills 目录：

```
# Windows
%USERPROFILE%\.workbuddy\skills\format-references-endnote

# macOS / Linux
~/.workbuddy/skills/format-references-endnote
```
