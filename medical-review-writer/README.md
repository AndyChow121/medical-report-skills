# Medical Review Writer · 医学综述写作器

> 中文 | English

## 简介 / Introduction

**中文** — 快速完成医学综述的工作流引擎：大纲构建 → 主题总检索 → 连续写作 → 章节校验 → 合并定稿 → 引用格式化。适合「写医学综述 / 写文献综述 / 基于 PubMed 写 review」。

**English** — A fast medical-review workflow engine: outline → topic search → continuous writing → section check → merge → citation formatting. For "write a medical review / literature review / PubMed-based review".

## 核心能力 / Key Features

- 六步流水线 — Six-step pipeline
- 主题检索与连续写作 — Topic search & continuous writing
- 章节校验 + 引用格式化 — Section check + citation formatting

## 适用场景 / Use Cases

- 综述论文快速成稿
- 文献调研报告

## 快速开始 / Quick Start

- 中文：调用 Skill `medical-review-writer`，给出综述主题。
- English：Invoke Skill `medical-review-writer` with the review topic.

## 安装 / Install

把本目录复制到 WorkBuddy 的 skills 目录：

```
# Windows
%USERPROFILE%\.workbuddy\skills\medical-review-writer

# macOS / Linux
~/.workbuddy/skills/medical-review-writer
```
