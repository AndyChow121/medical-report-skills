# Basic Research Design Extractor · 基础研究设计提取器

> 中文 | English

## 简介 / Introduction

**中文** — 从一篇基础研究论文、摘要、全文或方法/结果内容，快速产出详细的 Markdown 实验方案：按检测指标拆分实验、复现步骤、机制验证计划，便于立项与重复实验。

**English** — From one basic-research paper, abstract, full text, or Methods/Results content, quickly produce a detailed Markdown experimental plan: experiments split by assay, replication steps, and mechanism-validation plan — handy for grants and replication.

## 核心能力 / Key Features

- 按检测指标拆分实验流程 — Experiments split by assay
- 复现步骤与机制验证计划 — Replication steps & mechanism-validation plan
- Markdown 可直接进课题文档 — Markdown drops straight into project docs

## 适用场景 / Use Cases

- 从已发表工作提炼可复现方案
- 研究生开题/实验设计参考

## 快速开始 / Quick Start

- 中文：调用 Skill `basic-research-design-extractor`，附论文或摘要。
- English：Invoke Skill `basic-research-design-extractor` with a paper or abstract.

## 安装 / Install

把本目录复制到 WorkBuddy 的 skills 目录：

```
# Windows
%USERPROFILE%\.workbuddy\skills\basic-research-design-extractor

# macOS / Linux
~/.workbuddy/skills/basic-research-design-extractor
```
