# Design Template

Use this template to quickly produce a detailed but fast basic research experimental plan from one article. The output should be a Markdown document and read like a reproduction workflow: start from literature evidence, reproduce database or sample findings, build models, validate phenotypes, test mechanisms, perform rescue, and finish with in vivo or tissue confirmation when supported.

## Extraction Checklist

Extract only what the article supports:

- Disease or biological context.
- Key molecule, pathway, cell type, phenotype, or intervention.
- Research question.
- Core hypothesis.
- Experimental models: cell, animal, organoid, tissue, database, or patient-derived material.
- Main perturbations: knockdown, knockout, overexpression, inhibitor, agonist, rescue, treatment, stimulation, infection, injury model, or stress condition.
- Groups and controls, including high/low expression groups, control/treated groups, knockdown/overexpression groups, inhibitor/activator groups, or rescue groups.
- Samples/materials used for each experiment: database samples, tissue samples, cell lines, animal tissues, conditioned medium, extracted protein/RNA, staining sections, serum/plasma, or assay-specific gene sets.
- Main assays: qPCR, western blot, ELISA, IF/IHC, flow cytometry, CCK-8, EdU, Transwell, wound healing, apoptosis, ROS, mitochondrial assays, RNA-seq, ChIP, luciferase, Co-IP, RIP, pull-down, animal phenotype, histology, etc.
- Primary outcomes and quantitative indicators: expression level, score, OD value, colony number, migration/invasion cell count, fluorescence intensity, protein band gray value, tumor volume, survival time, AUC, correlation coefficient, enrichment score, p value, pathway activity, etc.
- Mechanism chain.
- Validation logic: rescue, pathway inhibitor/activator, dual model validation, in vivo confirmation.

## Anonymization Rules

This skill is used to imitate article design logic, not to expose the exact molecular names from the source paper. In the final output:

- Replace specific genes with `基因A`, `基因B`, `基因C`.
- Replace transcription factors with `转录因子A` or `转录因子B`.
- Replace enzymes with `酶A` or `酶C`.
- Replace proteins with `蛋白A` or `蛋白G`.
- Replace pathways with `通路A`, `通路B`, or `信号通路D`.
- Replace lncRNAs, circRNAs, and miRNAs with `lncRNA-A`, `circRNA-B`, `miRNA-C`.
- Replace drugs, compounds, or inhibitors with `药物A`, `化合物B`, or `抑制剂C`.
- Replace metabolites with `代谢物A`.
- Keep disease names, model types, cell/animal categories, assays, databases, and phenotype terms unless the user asks to anonymize everything.
- Use the same placeholder consistently across the whole output. For example, if the source article's main gene is mapped to `基因A`, keep `基因A` everywhere.
- Do not include a mapping table from placeholders to real names unless explicitly requested.

## Markdown Document Rules

- Output raw Markdown directly. Do not wrap the answer in ```markdown fences.
- Start with one H1 title: `# <课题名称>`.
- Use H2 headings for major document sections.
- Use H3 headings for reproduction stages.
- Use H4 headings for individual subexperiments.
- Use bullets for fixed fields inside each subexperiment.
- Use Markdown tables only where they improve scanning, especially for `关键对照`, `技术路线`, or compact summaries.
- Do not output HTML.
- Do not add explanatory text before or after the Markdown document.

## Granularity Rules

- Generate 4-7 major experiments by default.
- Each major experiment should be written as a reproduction stage labelled `阶段1`, `阶段2`, etc.
- Each stage should contain 2-5 subexperiments labelled by reproduction order, such as `实验1.1`, `实验1.2`, `实验2.1`.
- Treat each subexperiment as one concrete reproduction step. Every subexperiment must include the eight fields: 目的、模型、实验分组、样本、检测方法、检测指标、预期结果、备注.
- Different detection methods must be split into different subexperiments. For example, do not write `qPCR、WB、IF检测表达` in one block; write `实验2.2：qPCR检测`, `实验2.3：western blot检测`, `实验2.4：免疫荧光定位`.
- Different phenotypes must be split into different subexperiments. For example, proliferation, migration, invasion, apoptosis, EMT, inflammation, metabolism, and stemness should not be collapsed into one block.
- Make the plan look substantial, but keep all details biologically plausible and grounded in the article. If a detail is not available, write `待定`.
- Use placeholder molecule names throughout the proposal. Do not write exact source-paper gene names in titles, hypotheses, grouping, indicators, expected results, or notes.
- Write `预期结果` as a forward-looking screening or validation result. Avoid wording like `基因A在疾病中显著下调` as a fixed article conclusion; prefer `筛选在疾病中显著下调的候选基因进入下一步验证`.

## Compression Rules

- If the article lacks in vivo experiments, keep `实验4` as rescue validation rather than inventing an animal model.
- If mechanism evidence is weak, mark the mechanism experiment as `机制探索` rather than definitive validation.
- If the article is mainly omics or database-based, add one wet-lab validation experiment but mark specific samples/models as `待定` unless provided.
- If the user asks for “更简版”, output 3-4 stages but still keep ordered subexperiments and the eight fields.

## Experiment Detail Standard

Every subexperiment must follow this level of detail:

```markdown
#### 实验X.Y：<实验名称>
- 目的：验证候选轴与目标表型（增殖+迁移）及EMT关联性。
- 模型：TCGA-LUAD转录组样本。
- 实验分组：Group (a) 高lncRNA-A；Group (b) 低lncRNA-A。
- 样本：EMT基因集评分、增殖评分、迁移相关基因表达。
- 检测方法：ssGSEA、Spearman相关、通路富集分析。
- 检测指标：EMT score、增殖score、迁移score、相关系数r。
- 预期结果：筛选与EMT、迁移和增殖评分显著相关的lncRNA-A进入下一步功能验证。
- 备注：EMT核心指标用上皮标志物、间质标志物和EMT转录因子集合表示，不输出具体基因名。
```

Adapt the fields to the paper:

- For cell experiments, `模型` should name the cell line or write `待定细胞系`; `样本` should name RNA/protein/cells/supernatant/stained cells; `检测指标` should include values such as relative mRNA, protein gray value, proliferation rate, migration cell count, apoptosis rate, ROS level.
- For animal experiments, `模型` should name the animal disease/tumor/injury model or write `待定动物模型`; `样本` should name tumor tissue, organ tissue, serum, or sections; `检测指标` should include tumor volume, body weight, histology score, positive staining area, survival time, or serum markers.
- For omics/database experiments, `模型` should name TCGA/GEO/single-cell/proteomics/metabolomics datasets if known; `样本` should name expression matrix, gene set score, cell cluster, clinical phenotype, pathway score, or survival data; `检测指标` should include score, logFC, HR, AUC, r, p value, FDR, NES.
- For mechanism experiments, include the pathway molecule and upstream/downstream relation in `目的` or `备注`.
- For rescue experiments, `实验分组` must include at least control, perturbation, and rescue groups when supported by the article.
- If exact details are missing, write `待定` for that field rather than omitting it.
- For all expected results, use screening or verification wording:
  - `筛选...进入下一步`
  - `验证...是否改变`
  - `获得...候选对象`
  - `若...则支持...`
  - `为后续...提供依据`

## Common Reproduction Module Library

Use these module patterns when the article supports them:

- `表达筛选`: differential expression, volcano plot, heatmap, paired tissue validation.
- `临床/表型关联`: high/low expression grouping, phenotype score, survival, correlation, ROC.
- `通路预测`: GSEA, GSVA, KEGG/GO enrichment, PPI, upstream transcription factor or miRNA prediction.
- `细胞模型建立`: treatment gradient, time course, knockdown/overexpression efficiency.
- `RNA检测`: qPCR for target molecule and pathway genes.
- `蛋白检测`: western blot for total/phosphorylated proteins and EMT/apoptosis/inflammatory markers.
- `定位检测`: IF/FISH/IHC for subcellular or tissue localization.
- `增殖检测`: CCK-8, EdU, colony formation.
- `迁移侵袭检测`: wound healing, Transwell migration, Matrigel invasion.
- `凋亡/周期检测`: Annexin V/PI, caspase activity, cell-cycle flow cytometry.
- `代谢/氧化应激检测`: ROS, MMP, ATP, lactate, glucose uptake, OCR/ECAR.
- `互作验证`: Co-IP, RIP, ChIP, pull-down, dual luciferase, EMSA.
- `rescue验证`: knockdown plus overexpression, inhibitor plus agonist, mutant plasmid rescue.
- `动物验证`: xenograft, orthotopic, disease/injury model, treatment model, tissue staining.
- `组织验证`: HE, Masson, IHC, IF, TUNEL, western blot or qPCR in tissue.

## Writing Style

- Use direct, proposal-like Chinese.
- Use short bullets.
- Avoid literature-review paragraphs.
- Avoid exaggerated claims such as “首次证明” unless the article explicitly supports it.
- Do not include citations unless the user asks.
