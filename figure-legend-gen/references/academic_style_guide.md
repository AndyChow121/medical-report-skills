# 学术图注风格指南

## 总体原则

1. **自包含**：图注应在不阅读正文的情况下即可理解
2. **精确**：使用具体的测量值、样本量和统计检验方法
3. **简洁**：避免与正文内容重复
4. **标准化**：遵循特定期刊的格式要求

## 结构

### 必要元素
1. **简短标题** - 一行描述主要发现
2. **样本描述** - 测量了什么以及在什么样品中测量
3. **样本量** - 所有实验的n值
4. **统计数据** - 使用的检验方法和显著性阈值
5. **定义** - 缩写和符号的说明

### 可选元素
- 比例尺（显微镜）
- 颜色键（热图）
- 门控策略（流式细胞术）
- 分子量标记（Western blot）

## 统计符号说明

| 符号 | 含义 |
|------|------|
| * | p < 0.05 |
| ** | p < 0.01 |
| *** | p < 0.001 |
| ns | 无统计学意义（p ≥ 0.05） |
| § | p < 0.05 vs 对照 |

## 常用缩写

| 缩写 | 全称 |
|------|------|
| SEM | 均值标准误差 |
| SD | 标准差 |
| IQR | 四分位距 |
| CI | 置信区间 |
| ns | 无统计学意义 |
| WT | 野生型 |
| KO | 基因敲除 |
| OE | 过表达 |

## 期刊特定要求

### Nature系列
- 每个图注最多350个单词
- 图注中不包含方法（使用方法部分）
- 首次使用时定义所有缩写

### Cell Press
- 图编号加粗
- 图注中定义统计显著性
- 始终需要提供样本量

### Science
- 优选简洁的描述
- 适当时引用补充方法
- 所有图像均需要比例尺

## 语言规范

### 主动语态与被动语态
- 强调动作时使用主动语态
- 动作执行者未知或不重要时使用被动语态

### 示例
- **佳例**："Treatment with X reduced cell proliferation by 50%."
- **避免**："Cell proliferation was reduced by treatment with X."

### 时态用法
- 描述已进行的实验时使用过去时
- 陈述普遍事实和研究发现时使用现在时

### 示例
- **过去时**："Cells were treated with..."
- **现在时**："Data represent mean ± SEM..."
