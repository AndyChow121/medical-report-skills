# Figure Legend Generator · 医学科研图注生成器

> 中文 | English

## 简介 / Introduction

**中文** — 为科学图表生成标准化图注：支持条形图、折线图、散点图、箱线图、热图与显微镜图像。仅生成文字图注（含统计标注与缩略语说明），不生成可视化图像。

**English** — Generate standardized figure legends for scientific charts: bar, line, scatter, box, heatmap, and microscopy images. Produces text legends only (with statistical annotations and abbreviation notes) — does not render images.

## 核心能力 / Key Features

- 6 类图表的标准化图注 — Standardized legends for 6 chart families
- 自动统计标注与缩略语表 — Auto statistical annotations & abbreviation list
- 纯文字输出，不渲染图像 — Text-only output, no image rendering

## 适用场景 / Use Cases

- 论文投稿前的图注快速起草
- 组会幻灯片配图说明

## 快速开始 / Quick Start

- 中文：调用 Skill `figure-legend-gen`，上传图表并说明实验背景。
- English：Invoke Skill `figure-legend-gen` with the figure and its experimental context.

## 安装 / Install

把本目录复制到 WorkBuddy 的 skills 目录：

```
# Windows
%USERPROFILE%\.workbuddy\skills\figure-legend-gen

# macOS / Linux
~/.workbuddy/skills/figure-legend-gen
```
