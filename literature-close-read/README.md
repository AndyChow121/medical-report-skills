# Literature Close-Read · 文献精读报告

> 中文 | English

## 简介 / Introduction

**中文** — 从论文完整的 PDF→Markdown 文本（含 `## Page XX` 页码与图片引用）生成结构化精读报告，系统提取背景、研究问题、方法、结果、局限与可复现的实验细节，便于二次利用。

**English** — Produce a structured close-reading report from a paper's full PDF-to-Markdown text (with `## Page XX` pagination and image references), systematically extracting background, research questions, methods, results, limitations, and reproducible experimental details for downstream reuse.

## 核心能力 / Key Features

- 按页码/图片引用的结构化提取 — Structured extraction with page & image refs
- 覆盖背景/问题/方法/结果/局限 — Covers background/questions/methods/results/limits
- 可复现实验细节单独成节 — Reproducible experimental details sectioned out

## 适用场景 / Use Cases

- 组会/读书会的精读笔记
- 为课题设计或手稿积累材料

## 快速开始 / Quick Start

- 中文：调用 Skill `literature-close-read`，提供论文 PDF。
- English：Invoke Skill `literature-close-read` with the paper PDF.

## 安装 / Install

把本目录复制到 WorkBuddy 的 skills 目录：

```
# Windows
%USERPROFILE%\.workbuddy\skills\literature-close-read

# macOS / Linux
~/.workbuddy/skills/literature-close-read
```
