# Clinical Research Design Extractor · 临床研究设计提取器

> 中文 | English

## 简介 / Introduction

**中文** — 从一篇临床研究论文快速产出中文立项风格的临床研究方案：疾病负担、研究依据、目标、方法、终点、统计、伦理与产出，契合基金/伦理申报格式。

**English** — From one clinical paper, quickly produce a Chinese grant-style clinical study proposal: disease burden, rationale, objectives, methods, endpoints, statistics, ethics, and outputs — aligned with funding/IRB submission formats.

## 核心能力 / Key Features

- 立项风格中文方案 — Chinese grant-style proposal
- 覆盖终点/统计/伦理/产出 — Covers endpoints / statistics / ethics / outputs
- 契合基金与伦理申报 — Aligned with funding & IRB submission

## 适用场景 / Use Cases

- 临床课题立项书起草
- 从文献反推研究设计要点

## 快速开始 / Quick Start

- 中文：调用 Skill `clinical-research-design-extractor`，附临床论文或摘要。
- English：Invoke Skill `clinical-research-design-extractor` with a clinical paper or abstract.

## 安装 / Install

把本目录复制到 WorkBuddy 的 skills 目录：

```
# Windows
%USERPROFILE%\.workbuddy\skills\clinical-research-design-extractor

# macOS / Linux
~/.workbuddy/skills/clinical-research-design-extractor
```
