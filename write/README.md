# Natural Rewrite · 自然改写

> 中文 | English

## 简介 / Introduction

**中文** — 去除文本中的「AI 味」，把稿件改写得更自然、像人写的。支持中英文润色、去 AI 味、发布说明（release notes）、社交文案、产品本地化审校与长文结构打磨，保留原意与作者语气，不做过度修饰。适用于草稿、文档、发布说明、上线文案与社媒帖文的改写与审校。

**English** — Strip AI patterns from prose and rewrite it to sound human. Supports Chinese/English polishing, de-AI rewriting, release notes, social copy, product localization review, and long-form structural editing—preserving meaning and author voice without over-editing. For drafts, docs, release notes, launch copy, and social posts.

## 核心能力 / Key Features

- 去 AI 味：识别并改写套路化、表演性「提升感」表达 — De-AI: recognize and rewrite formulaic, performative "improvement" phrasing
- 中英双语润色与本地化审校 — Chinese/English polishing and localization review
- 长文结构打磨，保留作者语气 — Long-form structural editing, preserves author voice
- 发布说明 / 社交文案专项打磨 — Release-notes / social-copy specialist passes

## 适用场景 / Use Cases

- 把 AI 生成的初稿改得像人写、过审不露痕迹
- 发布说明、上线文案、推特/X 帖文、多语言 i18n 文案润色
- 文档/长文连贯性与段落结构审校

## 快速开始 / Quick Start

- 中文：在 WorkBuddy 中说「去 AI 味 / 润色这段 / 写一段发布说明」并附文本；或直接调用 Skill `write`。
- English：In WorkBuddy say "remove AI taste / polish this / draft release notes" with the text, or invoke Skill `write`.

## 安装 / Install

把本目录复制到 WorkBuddy 的 skills 目录：

```
# Windows
%USERPROFILE%\.workbuddy\skills\write

# macOS / Linux
~/.workbuddy/skills/write
```
