# 文风画像提取

当用户提供的是示例文本，而不是抽象风格描述时，先从示例中提取可执行的文风画像，再用它指导改写。

## 目标

不要把示例文章拆成写作结构蓝图，也不要输出冗长评论。只提炼会直接影响改写的风格特征。

## 提取维度

至少覆盖以下维度：

- 语气强度：克制、平静、坚定、尖锐、煽动、劝导
- 正式程度：口语、半书面、正式书面、学术
- 句式习惯：短句密集、长句铺陈、长短交替、排比、设问、反问
- 节奏推进：缓慢展开、连续推进、层层递进、跳跃切换
- 用词倾向：抽象/具象，朴素/华丽，评论化/说明化
- 修辞偏好：比喻、对照、引用、反复、排比、留白
- 叙述视角：我/我们/第三人称/旁观评论
- 情绪显露：低、适中、高
- 段落习惯：短段、长段、先判断后展开、先叙述后评价

## 提取方法

1. 先看稳定特征，不抓偶发句子。
2. 用 5 到 8 条短句写出文风画像。
3. 区分“风格”与“内容”。
   例如，某个比喻、某个观点、某个案例通常属于内容，不应直接迁移。
4. 如果示例风格混杂，指出主风格和次风格，并在改写时只保留主风格。

## 输出形式

内部可使用列表或简短字段化摘要，不必输出 JSON。

示例：

- 语气克制，不煽情，但带明确判断。
- 长短句交替，常用短句收束段意。
- 用词偏书面，少口语词，少感叹。
- 修辞密度低，主要依靠对照和递进形成力量。
- 常先给结论，再补充解释。

提取完成后，立即进入改写，不要停留在分析阶段。
