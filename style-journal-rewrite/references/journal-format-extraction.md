# 期刊格式提取

当用户提供目标期刊的投稿指南、作者须知或已发表文章时，先提取“可执行的显性格式要求”，再据此改写初稿。

## 目标

提取那些能直接影响改写结果的规则，不做泛泛总结，不臆造未提供的期刊规范。

## 优先提取项

优先按下面顺序扫描并记录：

- 文章组成部分及顺序
  例如：标题、摘要、关键词、引言、方法、结果、讨论、结论、致谢、参考文献。
- 摘要要求
  例如：单段摘要还是结构式摘要，是否必须分为 `Objective/Methods/Results/Conclusion`，字数或词数限制。
- 关键词要求
  例如：数量范围、是否需按特定规则书写。
- 正文结构
  例如：一级二级标题是否编号，是否要求 IMRaD 结构，章节名是否固定。
- 参考文献
  例如：文内引文是数字上标、方括号编号还是作者-年份；文末条目顺序、作者书写规则、期刊缩写方式；编号样式是 `[1]`、`1.` 还是 `¹`；是否包含 DOI/PubMed 链接。
- 其他显性格式
  例如：图表标题位置、计量单位写法、缩略词首次出现规则、致谢或基金声明位置。

## 证据优先级

按以下优先级判断规则强度：

1. 投稿指南中明确写出的规则
2. 多篇样文中稳定重复出现的规则
3. 单篇样文中的局部样式，只能视作弱提示

如果某条规则只有单篇样文支持，不要把它写成“必须”。只能把它作为“可优先贴合”的样式。

## 输出形式

内部整理成一份极简格式画像，至少包括：

- 必须满足的显性规则
- 可优先贴合的弱规则
- 无法确认的部分

示例：

- 必须：摘要为 1 段，限 300 词；关键词 3 到 5 个；参考文献采用方括号编号。
- 必须：正文使用 `Introduction/Methods/Results/Discussion` 四段式结构。
- 弱规则：样文多为三级标题，不强制编号。
- 未明确：图注位置、基金声明模板。

## 落地原则

1. 能直接改的先改。
   例如摘要段落数、章节顺序、关键词数量、参考文献展示形式。
2. 需要额外信息的，不虚构。
   例如作者单位、伦理审批、基金编号。
3. 格式要求与原稿信息冲突时，优先保留事实，再尽量贴近期刊格式。
4. 若参考文献原始信息不足以完全转换格式，保守调整已有字段，不编造缺失字段。
