# Reference Retrieval · 文献检索式构建

> 中文 | English

## 简介 / Introduction

**中文** — 按中/英文意图直接查找文献，或自动构建 PubMed 布尔检索式并检索筛选，适合快速补全引用与获取主题证据。

**English** — Find literature from CN/EN intent directly, or auto-build PubMed boolean queries and screen results — for quick citation completion and topic evidence.

## 核心能力 / Key Features

- 中/英文意图直接检索 — Search from CN/EN intent directly
- 自动构建 PubMed 布尔式 — Auto PubMed boolean query building
- 结果筛选与去重 — Result screening & dedupe

## 适用场景 / Use Cases

- 快速找某主题高质量证据
- 为综述/手稿补全检索

## 快速开始 / Quick Start

- 中文：调用 Skill `reference-retrieval-skill`，描述想查的内容。
- English：Invoke Skill `reference-retrieval-skill` describing what to find.

## 安装 / Install

把本目录复制到 WorkBuddy 的 skills 目录：

```
# Windows
%USERPROFILE%\.workbuddy\skills\reference-retrieval-skill

# macOS / Linux
~/.workbuddy/skills/reference-retrieval-skill
```
