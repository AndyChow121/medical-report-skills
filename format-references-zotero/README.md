# Format References (Zotero) · Zotero 文献排版

> 中文 | English

## 简介 / Introduction

**中文** — 将手稿中的 [PMID:xxxx] 转为 Word(.docx)，写入原生 Zotero 域代码（ADDIN ZOTERO_ITEM / ADDIN ZOTERO_BIBL），在 Word 中点一次「Refresh」即完成排版；内置 search_styles.py 可下载任意 CSL 样式（Science/Nature/Vancouver/APA 等）。仅适用于 Zotero 用户。

**English** — Convert manuscript [PMID:xxxx] into Word (.docx) with native Zotero field codes (ADDIN ZOTERO_ITEM / ADDIN ZOTERO_BIBL); one "Refresh" in Word finishes formatting. Bundled search_styles.py downloads any CSL style (Science/Nature/Vancouver/APA). Zotero users only.

## 核心能力 / Key Features

- [PMID] → Word + Zotero 域代码 — [PMID] → Word + Zotero field codes
- 内置 search_styles.py 下载 CSL — Bundled search_styles.py for CSL styles
- 仅 Zotero 工作流 — Zotero workflow only

## 适用场景 / Use Cases

- Zotero 用户的参考文献终排版
- 切换/下载引用样式

## 快速开始 / Quick Start

- 中文：调用 Skill `format-references-zotero`，附含 [PMID] 的手稿。
- English：Invoke Skill `format-references-zotero` with the [PMID]-tagged manuscript.

## 安装 / Install

把本目录复制到 WorkBuddy 的 skills 目录：

```
# Windows
%USERPROFILE%\.workbuddy\skills\format-references-zotero

# macOS / Linux
~/.workbuddy/skills/format-references-zotero
```
